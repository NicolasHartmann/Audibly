# Tags for Audiobooks (Windows) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Own tags per book (single and bulk editing), Audible genres as suggestions, library filter by tag, listening time per tag.

**Architecture:** Tags are one text column per book, one tag per line. Tag rules (parse, merge, filter) live in `Audibly.Core/Tags`, listening time per tag in `Audibly.Stats`, the UI in `Audibly.App`.

**Tech Stack:** .NET 8, EF Core 9.0.7 + SQLite, xunit, WinUI 3.

**Spec:** `docs/superpowers/specs/2026-11-20-tags-design.md`

## Global Constraints

- Tags compare case-insensitively; the spelling already present in the library wins. Trimmed, empty lines dropped, no duplicates.
- `Genres` stays as Audible's raw data; `Tags` is the user's list. Nothing deletes tags except the user.
- Filter: status filter AND (book has at least one of the ticked tags). No tag ticked = no tag filter.
- "No tag" bucket in the stats so the sum matches the total.
- Saving many books runs off the UI thread in one repository call.
- UI texts are English. Windows only.

## Review Focus

- A book whose `Tags` is null or has blank lines / stray spaces: parses to a clean list, never shows an empty chip. (Task 1 test.)
- Adding "fantasy" to a library that already has "Fantasy": stays one tag spelled "Fantasy". (Task 1 test.)
- Bulk remove of a tag only some selected books have: removed where present, others untouched; unselected books never change. (Task 1 test on `TagList.Remove`; Task 5 manual.)
- "Look up online" on a book with own tags: own tags stay, found genres are added. (Task 3 test.)
- A listening slice for a book that was deleted from the library: counted under "No tag", sum still equals the total. (Task 4 test.)

## Deviations from the spec (ruled)

- Multi-select via a "Select" mode button instead of Ctrl/Shift-click: the library is an `ItemsRepeater`, which has no built-in selection; a mode toggle is simpler and does not clash with click-to-open.
